# `source.jax_diff` documentation set

Companion documentation for the differentiable JAX port of FuelLib
landed on the `copilot/jax-integration-adjoint-study` branch.

| Document | Purpose |
|----------|---------|
| [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md) | The design plan: motivation, scope decisions, workstream breakdown (W1–W7), and acceptance criteria. |
| [`TASKS_COMPLETED.md`](./TASKS_COMPLETED.md) | Concrete record of what shipped on this branch, organised by workstream, with a test inventory. |
| [`REMAINING_WORK.md`](./REMAINING_WORK.md) | Items from the plan that were deferred, plus known limitations and follow-up recommendations. |
| [`CAPABILITY_USAGE.md`](./CAPABILITY_USAGE.md) | Practical "how do I run this and what can I do with it" guide with five concrete use cases. |

For a module-by-module API reference see
[`source/jax_diff/README.md`](../../source/jax_diff/README.md).
